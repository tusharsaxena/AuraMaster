# Text glow: implementation plan

> This runs as a Workflow orchestration (ultracode). Each task has an implementer, then an independent
> reviewer with up to two fix rounds. A whole-branch multi-lens review with adversarial verification
> follows, then a checkpoint. Tasks run in order, because they share files.

**Goal:** an opt-in soft glow behind a text container's text (owner request, 2026-10-15).

**Spec:** `docs/superpowers/specs/2026-10-15-text-glow-design.md` (binding).
**Branch:** `feat/2026-10-15-text-glow`, from `master` at `d0eb01b`, in the main AuraMaster tree.

## Rules for every task

- Test-first, with a true `-- red under:` note on each case.
- The green gate before every commit: `ka0s-bounded lua tests/run.lua`, and `ka0s-bounded luacheck .`
  at 0/0. `ka0s-bounded` is `/home/tushar/.claude/dev-copilot/bin/ka0s-bounded`.
- No function above CCN 15 (`bash tests/_kit/run-automated-tests.sh --suite complexity`, its bundle
  deleted after). No authored Lua file past 1500 lines.
- Any case change regenerates `docs/test-cases.md` (`lua tests/run.lua --list > docs/test-cases.md`)
  and updates the README badge.
- Doc citations move in the same commit as the lines they point at.
- Keep CRLF line endings, US spelling and the surrounding comment voice. Mock changes go only in
  `tests/wow_mock.lua`.
- A deviation from the Ka0s WoW Addon Standard is flagged to the orchestrator and never absorbed.
- A commit subject starts with `<ID>: `, and the message ends with the session trailers.
- No merge, no version bump and no tag. Push the branch at checkpoints only.
